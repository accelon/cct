本輪關鍵發現：Unihan 的等價類裡有髒資料

差字對統計冒出 緑→氯 31 次。先懷疑 n1 表壞了——查實不是（29 個可疑字全部折到自己）；真正原因是 kSemanticVariant 的語意為「某些語境同義」，不等於可互換。
剔除字原本被併進為什麼是錯的剔除後該差字對變成
氯綠 的同类氯是近代化學用字，只因同「录」聲旁而被收進同一類緑 → 綠（31 次，正經異體）
嶩的 的同类與「的」無互換關係得 → 旳
傌罵 的同类罕用字，非異體駡 → 罵
螫著／着 的同类「毒蟲螫人」不能與「著」互換；但 著/着 本身必須留保留 413 條 着→著
等價類 1,950 → 1,946 字 產量不變（這四字在小說語料極少出現） n1／textHash 完全未動 → 四庫既有 hash 未漂移 教訓：kSemanticVariant 只能當候選，逐條篩過才能當等價類
