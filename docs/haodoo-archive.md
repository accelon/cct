## 2. 抓取方式：溫柔模式

第一輪曾用併發 3／250 ms，短時間打了近千個請求，雖然網站沒有回 429/403，但對志工小站
太急。已全面改成：

- **單執行緒**，請求間隔 1,200 ms ＋ 0–800 ms 隨機抖動（約 0.6 req/s）
- 每 150 個請求休息 30 秒
- 遇 429／503／403 依 `Retry-After` 退避，並對本輪永久降速
- 已存檔自動跳過，任何階段可中斷續抓；`HAODOO_MAX_REQUESTS` 可限制單輪請求數
- 每個檔案留 url／sha256／bytes／ETag／Last-Modified

單次探測確認改完後網站仍回 HTTP 200、無 `Retry-After`，沒有觸發防護。
全程 8,079 個請求裡失敗 0 筆。

## 3. 格式比對：只取好讀原生 updb

同一本書站上提供多種格式，實際下載 `吶喊`(435)、`四世同堂`(404)、`邊城版本二`(1010490145)
等比對：

| 格式 | 結構 | 判斷 |
|---|---|---|
| **updb** | Palm PDB，`type=BOOK`／`creator=MTIU`；record 0 是目錄，其後一筆一章，**未壓縮 UTF-16LE**，末筆 `\uffff` 結束 | ✅ 好讀原生 Unicode 版，**選它**（4,139 本） |
| epub | zip + OPF spine + XHTML，由 updb 轉出 | 備援，實際用在 22 本沒有 updb 的分享書。與 updb 正文相似度 **0.96**；`吶喊` 漢字數 68,283 vs 68,372，差異只在直式標點（︽︾﹁﹂︱︱ →《》「」——）與 epub 重複的章名 |
| pdb | 早期 Big5 | 僅 2 本沒有其他格式時才抓；實測這 2 本內容仍可解出 |
| prc / mobi | PalmPilot／MOBI（`BOOKMOBI`，PalmDoc 壓縮） | 不解、不抓 |

updb 還多保留了 **目錄、校書記略、版次**（例如「《二○一七年四月七日版》《好讀書櫃》典藏版」），
比 epub 更接近原稿。因此每本只抓一種：`updb → epub → pdb → prc → mobi`；
其餘格式網址記在 `manifest/formats.tsv`（19,430 筆），不重複下載。

⚠ **下載代碼必須取書頁按鈕上的實際參數**：`14W6` 的 updb 是 `H14W6`，讀者分享書是 `P` 前綴，
一般書才是 `A` 前綴；自行推導會 404。

### 最終解碼成果

`src/decode-haodoo-text.py` 以純標準庫解 PDB records 與 EPUB OPF spine，輸出逐本純文字與逐章索引：

- **4,163／4,163 本全數解出，失敗 0 本**；122,591 章、**631,860,506 個漢字**（約 6.32 億）
- 格式分布：updb 4,139、epub 22、pdb 2
- `四世同堂`：102 章、605,684 漢字；`吶喊`：16 章、68,283 漢字
- 保留原繁體、原標點，不簡轉繁、不改字

## 4. 勘誤表：三層保存

書可以重做，網友逐字校對的痕跡不能重來。書頁上的勘誤段格式為
「勘誤表：(貢獻者 日期) 錯字/正字 …（未改…）」，處理方式：

1. **原始 HTML** `html/books/` — 完全不動
2. **逐字原文** `text/errata/<id>.txt` — 含所有說明、括號備註、空行；檔頭記來源與 sha256
3. **結構化清冊** `manifest/errata.tsv`（逐條：貢獻者／日期／錯字／正字／備註）
   與 `manifest/errata-people.tsv`（逐位貢獻者：批次、改字數、跨幾本書、起訖日期）

另外把周劍輝親筆《勘誤需知》（2013/7/20，2016/3/25 修）與《徵初步整理、校正》
1a／1b／2／3 各期清單獨立存到 `text/errata/site/`，共 6 份站方文獻。

**全站最終成果**：4,259 個書頁中 **1,873 本有勘誤段**（2,386 本無），
抽出 **191,100 列**，其中 **157,479 條改字**，共 **1,311 位貢獻者**。
抽樣時看到的大奇、mPDB、sue1289、薛嚴嚴、A Yung、Gilbert、Joy、SYChang、man、
Nightfifty、蟻滿長安、Fong、張秀雲、水木清華等名字，如今都在
`manifest/errata-people.tsv` 裡，連同每人的批次、改字數、橫跨幾本書與起訖日期。
這是二十年來無數網友一筆一筆留下的痕跡，也是這份留存最不能取代的部分。

## 6. 執行紀錄與兩處修正

| 階段 | 結果 |
|---|---|
| site | 994 頁，失敗 0 |
| inventory | 4,259 種（目錄 4,090 ＋ 站內發現 169） |
| books | 4,259／4,259，失敗 0 |
| parse | 選定格式 updb 4,139／epub 22／pdb 2／無 96；格式連結 19,430 筆 |
| files | 4,163／4,163，1,560 MiB |
| decode | 4,163／4,163，122,591 章、631,860,506 漢字，失敗 0 |
| errata | 191,100 列、157,479 條改字、1,311 位貢獻者、站方文獻 6 份 |

途中修正兩處，都已寫回程式：

1. **分享書頁的 `M` 參數大小寫**：清冊裡 1,433 筆讀者分享書寫成小寫 `M=share`，
   實測回 `400 Invalid module.`，大寫 `M=Share` 才回 200。原本會缺掉 1/3 書頁，
   並對網站送出數千個必然失敗的重試請求。已在 `stageBooks` 正規化
   （連帶把站內發現的相對網址補上 BASE），停止舊行程後重跑，已抓的書頁全保留。
2. **EPUB 解碼兩處假設**：`zipfile.ZipFile` 需要 `io.BytesIO` 包裝 bytes；
   且部分 OPF 把 `href` 寫在 `id` 前面，改為逐標籤取值。22 本 epub 因此全數解出。

⚠ **進度口徑**：`crawl.log` 的 `N/4259` 是**已處理數（含失敗）**，不是完成數；
`book-pages.tsv`／`books.tsv` 是階段結束才寫入。要算百分比請數目錄裡的實際檔案，
分母是「書頁 4,259 ＋ 書檔總數」（實際有格式者為 4,163）。

## 7. 版權邊界

好讀站方聲明書籍版權歸原作者／發行商。本次為**私人語料分析與紀念性保存**，
檔案只存本機，不發布、不上傳、不進版控、不商用；正文若要另行使用，仍須依
[`docs/haodoo-holdings.md`](haodoo-holdings.md) 的公版規則（作者卒年＋50 年）逐本判斷。
勘誤表、書頁說明、讀者來信等站方／讀友自撰文字，僅供研究與存檔引用。

站外連結（`haodoo.blog`、`haodoo.org`）不在本次範圍；若日後要一併留存，
另行評估，避免這次對主站增加額外請求。
