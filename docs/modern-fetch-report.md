## 四、來源記錄（catalog 欄位）

`ws_title｜book｜author｜cites｜via｜similarity｜pageid｜revid@ts｜pd_basis｜author_page｜pd_author｜errk｜wt_bytes｜wt_gz_bytes｜nowiki_chars｜nowiki_gz_bytes｜han_density｜children｜keep｜sha256_wt16｜sha256_nowiki16｜fetch_utc｜url`

- `pd_basis`：作品頁的 PD 模板（37 種有，如 `Pd`）
- `pd_author`：作者頁模板（主目錄 78 種查到；展開的子頁 113/113 全數＝`Author:老舍`）。
  **回查規則已獲用戶核准（2026-11-07）**：核准範圍、回查鏈（頁內 Author 連結 → 字典作者欄位 → `Author:<名字>`）、
  已知限制（譯作／合集／圖版等保護期另算）——正式定義見 `modern/catalog-README.md` §一（工作區副本 `cct/data/modern-catalog-README.md`）。
- `errk`：作者頁查無模板／站內繁簡轉換標記（`{{傳統漢字化}}`，1 種；這關係到之後比對的字形前提）
- `via`：`exact / redirect / search-exact / cache-rebuild / notfound`
- `sha256`（16 碼）：原文與清洗後各一份，供日後驗「清洗是否可重現」
- `url`：每列可回溯原頁

## 五、踩過的坑（都已在碼裡註解）

1. **繁簡標題不是同一個字**：正體「茶館」vs 簡體「茶馆」碼位不同，我用碼位相等判同，害 25 本被判 notfound。
   → 改用本區現成的 s2t 摺疊表（`foldKey`）比標題。
2. **搜尋相似度會騙人**：《三千里江山》被配到政治文章「朝鲜三千里江山一定要统一」、
   《大波》配到「…民间借贷纠纷一审民事判决书」、《三里灣》配到《欽定古今圖書集成》卷246。
   → 取消相似度接受，只認摺疊後完全相等，其餘一律 notfound（宁可缺，不可错）。
3. **索引頁模板是 `{{Collection header}}`（有空格）**：我寫死無空格 → 18 本長篇索引全被誤標「過短」。
4. **HTTP 429**：每本 4 個請求太密 → 改為全域節流＋`retry-after` 指數退避；重跑目錄走本地快取，不再打站方。
5. **作者連結不在 wikitext 裡**：我原本只找 `[[Author:…]]`，本站多用其它寫法 → 回退用字典作者欄位查作者頁，PD 依據因此才收到 78 種。
