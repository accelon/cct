## 4b. 已做：n2 語義異體級（贖回 998 條）

你後來要的是「擴 n1 收 Unihan 語義異體」。**我沒有動 n1**，理由有證據：
`data/char-fold.tsv` 是 gycd `norm_char(tier=1)`（`ancient-book-xref-spec` §4.4）的凍結複製，
四庫 textHash 全按它算；把 Unihan 併進去會讓既有 hash 漂移、且喪失與 gycd 的可比性。
所以另出一層 **`n2 = n1 ＋ Unihan 語義異體類`**，只在「找回引文」時用，**不参与 hash**。
表：`data/char-variant.tsv`（來源 `adb-converter\vendor\Unihan_Variants.txt`，本機既有、未抓網；
取 `kSemanticVariant`＋`kSpecializedSemanticVariant`＋`kZVariant`，不收繁簡欄——OpenCC 已在 n1 處理，
不收日文新舊體——不適用於字典）。共建 1,950 個字的代表字映射。

先講一句難聽但重要的：**我拿來當招牌的三個例子，Unihan 根本沒有互相关联**（`probe-unihan-pairs.mjs`）：
```
㘭(U+362D) 坳(U+5773) → 兩字都無任何變體欄位記錄
槍(U+69CD)            → 只有 kSimplifiedVariant=枪；與 鎗(U+9397) 無關
噯(U+566F) 曖(U+66D6) → 曖 的 kSemanticVariant 是 瞹(U+77B9)，不是 噯
```
也就是「版本異文／類書改寫」那部分 n2 救不了。但跑完的實際產出比預期好：

## 4c. 第三級：80% 容忍對齊（你後來拍的標準，贖回 2,147 條）

你說「80% 字元正確就算有用引文，版本傳抄錯字多的是」→ 加第三級：

```text
演算法：在引文上等距取 5 個 4 字探針 → 章內 indexOf 探針 → 反推起點，並在 ±2 位移內各試一次
        （省字／衍字會把整段推歪，只試單一偏移會有 1–2 字的對齊誤差）→ 同長視窗逐位比相同字比例
接受：score ≥ 80% 且唯一（最佳與次佳差 <0.05 → 判含糊，不硬鏈）
標記：kind="cite-fuzzy"，confidence=實際比例（80–99），與 cite／cite-var 三級不混帳
```

### 但這一級逼出一個必須講的發現：Unihan 的等價類裡有髒資料
差字對統計（`src/audit-fuzzy-links.ts`）出現了不該出現的組合：
```
緑→氯 31 次｜駡→傌 24 次｜得→嶩 11 次｜筯→着 6 次
```
我先懷疑是 n1 表壞了——查實**不是**（`probe-fold-suspects.mjs`：29 個可疑字全部折到自己）。
真正原因是 `Unihan_Variants.txt` 的 `kSemanticVariant` 本來就收「某些語境同義」而非「可互換」：
```
綠	氯	sem      ← 氯是近代化學字，只因同「录」聲旁被收進同一類
的	嶩	sem　　罵	傌	sem　　螫	着	sem
```
修法不是棄用整個欄位（`著/着`、`裏/裡` 那 413＋212 條靠它），而是**剔掉這 4 個髒成員**
（`make-variant-table.ts` 的 `DENY`）。等價類從 1,950 字變 1,946 字，產量不變（這四字在小說語料極少），
但差字對立刻回到正經異體：`緑→綠`、`駡→罵`、`顔→顏`、`産→產`、`閑→閒`、`槍→鎗`。

**教訓（寫下來）**：`kSemanticVariant` 不能直接當等價類用；要當「候選」，再按欄位逐條篩。
若當初我做了傳遞閉包又沒審查，`綠≡氯` 這種就會變成錯鏈的源頭。

## 4d. 規則修正：短引文只要完全命中也連（＋309 條）

你指出「引文 <8 字，只要完全命中也應該連」——**這是我設錯的門檻**。`QUOTE_MIN=8` 原為壓制*模糊*比對的噪聲，
但我在程式裡把它放在**所有級別之前**（`if (q.length < 8) → short 不鏈`），等於順帶砍掉 102,607 條精確可比的引文。

現行規則（`--min-han=2` 與 `--quote-min=8` 分開）：
```
精確級 ①n1 逐字／②n2 語義異體：引文 ≥2 漢字、且全書唯一命中 → 連
容忍級 ③80% 對齊：仍需 ≥8 漢字（5 個字的 80% 只有 4 字相同，沒有定位意義）
```

```text
連結 7,611 → 7,920（+309）｜搜不到 1,433 → 1,548｜多命中 12 → 26｜不足 2 字而不鏈 3,502
書名 855 → 878 種；hydzd 字頭 3,941 → 4,038
新增的 309 條：2–4 字 34｜5–7 字 275（其餘長度本來就在鏈）
```
抽查這批短連結（`node src/list-short-links.mjs` → `out/short-links.txt`），品質出乎我預期地好——
它們是**單字條目的書證片段**：〈趕〉『趕熱好喫。』bk010、〈扃〉『扃鍵如新。』bk090、
〈榼〉『銀粉榼成對。』bk322、〈汗〉『卿面何以汗？』bk132。這正是字典例證的常見形態，我原先那道門檻把它全擋了。

證據力差異仍保留給使用端判斷：引文長度在 `xout` 行第 7 欄（`n1(quote).length`），
要排除 2–4 字那 34 條，依該欄過濾即可，不需重跑。
