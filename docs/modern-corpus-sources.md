## 三、這代表什麼（我的判讀，非數據）

1. 「現代文學全集級」在**法律上**不是有或沒有，而是**遞延到期**：Top30 作者裡过半仍在保護期內，
   而其中最肥的幾位（魯迅 8,740）已到期、可在維基文庫取到全文（實測該頁標 PD：作者 1936 年逝、1929 年前出版）。
2. 毛澤東 1976＋50＝2026-12-31——**今年年底到期**，其 1,873 次引用（含《湖南農民運動考察報告》等 287 篇）
   明年起可自由使用。這是一個有明確日期的待辦。
3. 真正做不到的不是書，是**報刊**：《人民日報》998 次等 6,558 次報刊引文屬法人作品（首次發表後 50 年），
   逐篇計算成本極高；且全文只在機構訂閱的「人民日報图文資料庫」，開放側只有 1946–2003 的文字鏡像。

## 五、初判建議（已被 §七 修訂，留供對照）

1. **別追「現代文學全集」**。以本表估算，公有領域可得上限只有全庫引文的個位到十幾％，
   代價卻是整條新的採集管線（掃維基文庫、逐篇標 PD、繁簡對照）。
2. **先做零成本的 727 次**：xdhycd↔`jing`/`openlib`/`swjz` 的古典那一塊（前一份報告已量化）。
3. 若仍想要現代文學，**按第二節的書單只收前 10–20 本**（魯迅、老舍、朱自清、瞿秋白、許地山、
   郁達夫、趙樹理、洪深…）——这几位已到期且單本文字量可控，是最劃算的一批。
4. 把「毛澤東 2026-12-31 到期」記成日程，明年再回來收那 1,873 次。

## 六、追問：國內有「開源」的現代文學全集嗎？（本輪實查）

**結論先講：合規意義上「開源可下載的現代文學全集」並不存在；存在的是三條不同性質的通道。**

### 甲、最接近你要的東西：《限量复制民国时期图书》全文庫
由教育部高校圖工委文資組 2005 年啟動，四個專輯（一說複製圖書共 16,726 種／18,249 冊）：

| 專輯 | 種／冊 | 與本專案的關係 |
|---|---|---|
| 《中国近现代本土文学作品》 | 2,654 種／2,783 册 | **正中靶心**：1901–1949 我国出版之现代作家的文学作品 |
| 《中国近现代翻译文学作品》 | 3,172 種／3,447 冊 | 字典引翻译作品时可用 |
| 《民国籍粹》 | 10,192 種／11,054 冊 | 学术书为主，含期刊性质资料 |
| 《民国时期文献资料海外拾遗》 | 710 種／967 冊 | 补充 |

- 收录原则（原文）：「由中国近现代作家于 1901 至 1949 年间创作、并于这一时期刊行的单行本；**1949 年以后以单行本重印者不予选取**；同一种作品如有多种版本，尽可能采用最早的版本」——版本学上对我们极有利（引文比对最怕晚出改版）。
- 功能：全文检索＋**PDF 全文下载**，入口 `bnhw.hwshu.com`；有高校列为「免费资源」（浙大）、有馆称永久使用权（台州学院）、有馆已正式开通（南科大）。
- ⚠ **但这不是开下行**：走的是机构 IP／WebVPN 授权，且授权范围是「到馆／到校使用」。拿来建我们自己的公开 adb，几乎肯定超出授权。**它是研究比对用的来源，不是可以再发布的语料。**

### 乙、真・开下行（GitHub／HF）——但作者自己就说明了版权妥协
| 资源 | 规模 | 现实状态 |
|---|---|---|
| Alpha Modern Chinese Corpus（AMC，上外） | 完整版 680 万句／3.1 亿字（含 fictions） | 明确写「源数据受版权保护，**为避版权只提供句子不提供全文**」；仅限教研、禁商用 |
| ChineseBookCorpus | 压缩包 5.6 GB／解压 14.6 GB，含“当代文学”等粗分类 | 爬站汇总，初步清洗，**版权来源未审**；同一书可能重名重复 |
| MNBVC | 已积累 62 TB，目标 253 TB | 项目自己声明「没有能力对数据来源进行版权审核」，且**不提供索引与分类**以免被逐项识别 |
| MultiGenre-ChineseNovel | 260 部网络小说、105,851 句标注 | 起点中文网前 10 章，仅科研用途 |

这一层的共同点：**有量、无序、无版权链**。要做「字典引文↔原文」的精确对照，缺的恰恰是它们没有的东西（书目控制、版本、作者—卒年—授权状态）。

### 丙、把它换成数字（`src/list-modern-targets.ts`，引文≥30 次且非传统典籍）
```
入選 429 種
  甲類 作者已到期，可取公有領域全文 ：128 種／21,148 次＝22.4%   ← 不用申請任何授權
  乙類 仍在保護期，需授權           ：145 種／39,136 次＝41.5%   ← 這批才是「要談」的
  丙類 作者標記不可靠／卒年待查      ：156 種                     ← 逐位查證後才歸隊
清單：data/modern-target-titles.tsv（title/cites/author/status/note）
```
注意 `book-stats.csv` 的「主要作者標記」是**引文行上的署名，不等於著作權人**（例：《詩經》標「朱自清」），
所以丙類那 156 種多是這個原因，不是真的查不到。

⚠ **此處 22.4% 的估算已被實測推翻**（同日抓取，見 `docs/modern-fetch-report.md`）：
「作者到期」不等於「有人做過全文」。128 種實抓＋2 本索引頁 113 子頁展開後＝
**可用 135 篇（799,354＋178,944 字）、覆蓋引文 3,017 次＝3.20%**；另有 78 種（60.9%）開放平台上根本沒有。
结论方向不變（這 128 種是唯一不需授權的一塊），但**量級要下调一个数量级**。

## 七、所以我的建議變成三句
1. **不要找「開源的現代文學全集」**——不存在，且凡是聲稱開源的都自認沒做版權審核。
2. **維基文庫那條路只到 1.3%（實測）**：24 種可用，幾乎全是魯迅單篇＋朱自清一篇。
   真要吃下多一點，就得展開索引頁（四世同堂 60 子頁、駱駝祥子 25 子頁＝1,792 次引文），
   這比新增資料源便宜，建議先做。
3. **41.5%（乙類 145 種）走機構授權通道做「查證」而非「再發布」**：用《限量复制民国时期图书》核對引文出處與版本，
   产出不受版权限制的**书目事实**（哪本书、哪一版、哪一段），而不是把正文搬进我们的库。
